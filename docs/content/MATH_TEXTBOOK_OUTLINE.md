Lessons in Part 1 are numbered "unit-lesson" but the in lesson header the digits are reversed visually (e.g. "٢-٣" means unit 3 lesson 2 in print layout).

## Terminology (as printed in the books)

|---|---|

Digits: Eastern Arabic (٠ ١ ٢ ٣ ٤ ٥ ٦ ٧ ٨ ٩) everywhere, including operator expressions. Equations are written RTL, result on the left in practice items ("[ ] = ٢ + ٣", box at left).
Note for the app: the books use ٢ + ٣ = [ ] visually with the sum box at the end of the line in RTL reading order.

## Recommendation for a small exemplary set
Pick from Part 1:
1. Unit 2, الأعداد (٠ إلى ١٠), lessons 2-1 (numbers 1 to 3), 2-6 (compare > < =). Core number sense, easy picture counting.
   Activities: `counting` (emoji objects, numeral options; birds/fish/children), `listen_pick` (which numeral is "ثلاثة"?), `matching` (picture group to numeral or word).
2. Unit 3, الجمع ضمن العدد ١٠, lesson 3-2 (add within 5). Story picture then "٣ + ٢ = ?".
   Activities: `arithmetic` (a + b with number options), `counting` (count both groups first).
3. Unit 5, الأشكال الهندسية, lesson 5-2 (plane shapes: دائرة، مربع، مثلث، مستطيل). Cleanly different from numbers.
   Activities: `naming` (tap a shape to hear its name), `matching` (door to rectangle, sign to triangle), `listen_pick` (which one is مثلث?).

Optional from Part 2 (at most one): Unit 7 lesson 7-1 (add within 20) or Unit 6 lesson 6-1 (numbers 11, 12). Prefer Unit 6 (6-1) with `counting` if scope must stay small and counting-only; prefer Unit 7 if `arithmetic` should show a step up (sums to 20).
Subtraction (Unit 4, lesson 4-2 "٥ − ٢ = ٣") is a natural second `arithmetic` set if a fourth unit is allowed, but keep out of the minimal set.

Authoring cautions: all pictures in the books are illustrations, so use app emoji objects instead of copying. Number words and operator readings (زائد، ناقص، يساوي) should follow the book wording above. Use Eastern Arabic numerals in lesson text consistent with the books.
