---
name: Repeating completed units
description: Completed learning content must stay accessible for unlimited practice
---

Children must be able to repeat completed units and lessons any number of times. Saved completion is an achievement, not a reason to hide learning content or skip to another activity.

**Why:** The user reported that reopening completed units only showed completion/next-unit controls instead of the learning content, and explicitly requested repeated practice.

**How to apply:** Start a fresh activity attempt when opening a completed lesson. Offer replay at completion without deleting progress. Preserve the highest earned stars; repeated completion must not multiply rewards. Keep repeat controls available in both interface languages.
